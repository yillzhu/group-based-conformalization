# IEEE 39-bus security-dispatch audit

This experiment asks whether RCC has a useful niche after removing the two main
objections to the earlier workforce example: the decision data cover the entire
domain, and the predictive model is given enough relevant data and physics-based
features to be credible near secure operating points.

## Optimization model

The decision is the output of ten generators in the PGLib-OPF IEEE 39-bus system.
Outputs satisfy generator bounds and balance the nominal 6,254.23 MW load. The
objective is PGLib's linear generation cost. For each uncertainty realization,
correlated system, regional, and bus-level load errors are balanced using fixed
automatic-generation-control participation factors. With probability 0.05, one
connected transmission line is unavailable. A DC power flow is then solved.

The learned response is

```text
h(p, xi) = max(worst fractional line-rating violation,
               worst fractional generator-bound violation).
```

Thus `h <= 0` is secure and the target is
`P(h(p, xi) > 0) <= 0.10`.

The compact case data come from `pglib_opf_case39_epri.m` in PGLib-OPF v23.07.
The source case attributes the IEEE data and licenses them under CC BY 4.0. Only
the active-load, generator, and DC branch fields needed here are retained in
`src/conformal_cl/power/case39.py`.

## Data and model

Each training, partition-design, and final-calibration sample is independent. Half
of each sample is generated by hit-and-run over the complete bounded dispatch
polytope, so every relatively open part of the domain has positive probability.
The other half is sampled from the nominally secure region with at least 2% of
generator capacity available in each direction. This second component supplies
enough observations near the small part of the nine-dimensional polytope where a
10%-risk solution exists.

The predictor is histogram gradient-boosted 0.9-quantile regression. Its inputs
include normalized dispatch, generator headroom, and nominal signed DC line
utilizations. These are deterministic functions of the decision, not realized
outcomes. The partition-design sample is separate from the final calibration
sample.

Two local methods are reported. `local_diagnostic` is a residual regression tree;
it is useful only for detecting residual geography and is not RCC. `candidate_rcc`
uses the Chapter 4 queue geometry over a finite set of 200,000 candidates, with
the chapter's delta-based group-size restriction during partition design and an
independent final recalibration. A region is eligible only if the recalibrated upper
bound is nonpositive at **every** candidate in that region; the optimizer may not
select an individually feasible-looking point from an unresolved region. Because
its extrema and optimization are over a finite candidate set, it is an audit
analogue rather than an exact continuous RCC implementation.

## Initial result: no reliable advantage

The table reports cost and fresh Monte Carlo violation probability. Each risk
estimate uses 100,000 new uncertainty realizations.

| Seed | Global cost | Global risk | Safe-region RCC |
| ---: | ---: | ---: | :--- |
| 0 | 141,750 | 6.99% | no certified safe region |
| 1 | 146,271 | 11.02% | no certified safe region |
| 2 | 141,751 | 7.58% | no certified safe region |

The uncorrected model's marginal upper coverage on the independent calibration
sets is 88.8%--89.2%, close to the nominal 90%. Physics features also eliminate
the gross optimizer exploitation seen in preliminary formulations. Nevertheless,
RCC does not yield a valid, repeatable cost improvement. An earlier implementation
allowed selection of a point satisfying its local corrected prediction even when
other candidates in the same terminal region were unsafe. In seed 2 that rule
reduced cost to 140,894 but incurred 20.39% risk. The corrected safe-region rule
rejects that solution and every other terminal region in the three runs.

This correction identifies a concrete obstacle rather than merely increasing
conservatism. Partition design places a boundary where its own corrected prediction
is approximately zero. A slightly larger correction from the independent final
calibration sample then revokes the whole-region certificate. Any proposed remedy
needs a prespecified design-stage safety margin or a valid simultaneous calibration
argument; reusing final-calibration outcomes to move the boundary would recreate
the adaptivity problem.

This case should therefore remain a negative control unless a principled change
to the statistical guarantee or partition algorithm reverses the result across
many prespecified seeds. It should not be tuned until one favorable run appears.

## Run

```bash
python -m pip install -e '.[power]'
python experiments/power/run_audit.py --smoke
python experiments/power/run_audit.py --seed 0 \
  --output results/power/audit_seed0_rcc.json
```

The audit does not require Gurobi. A full seed uses 30,000 training, 15,000
partition-design, 15,000 final-calibration, and 200,000 candidate dispatches.
